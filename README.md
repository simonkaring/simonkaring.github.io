# simonkaring.github.io

Simon Karing's portfolio. A static Vite site with a progressively enhanced WebGL node network ("Living System").

## Development

```sh
npm ci
npm run dev        # http://127.0.0.1:5173
```

## Build and verify

```sh
npm run build      # outputs dist/
npx playwright install chromium webkit
npm test           # serves dist/ on :4321, runs Playwright + axe
npm run preview    # then: node scripts/shots.mjs (URL=http://127.0.0.1:4321)
```

## Deploy

`.github/workflows/deploy.yml` builds, tests and publishes `dist/` to GitHub Pages on every push to `main`.
One-time setup: repository Settings → Pages → Source: **GitHub Actions**.

## Structure

- `index.html`, `config/mac/index.html`: page entries (routes `/` and `/config/mac/`).
- `src/content/projects.js`: all case study content. `scripts/pages.mjs` renders the home work index (injected at `<!--work-list-->`) and the case study pages; `scripts/generate-work.mjs` writes them to `work/<slug>/index.html` (gitignored, regenerated by `predev`/`prebuild`).
- `public/work/`: reviewed, anonymised screenshots (WebP).
- `src/main.js`: theme, reveals, lazy-loads `src/network.js` (three.js).
- `src/network.js`: particle network; samples the rendered `<h1>` into points and morphs into a clustered system graph on scroll.
- `public/`: copied as-is.

Fonts: Geist and Geist Mono (SIL OFL) via `@fontsource-variable`.
